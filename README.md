# Tomorrow's Note

## Goal

You just want to create tomorrow's note, which respects your native Obsidian Daily Note feature.

## How to use

Use newly added icon on left side bar, or go `Ctrl + P` and call `Open tomorrow's daily note` command.

## Comment

My goal is only to let you create new tomorrow's note, nothing else, as I needed this plugin. This plugin will be very maintained as very simple and concise module. Wish you guys like it :)
